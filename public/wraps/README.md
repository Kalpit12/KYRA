# KYRA Wrap Assets

Replace placeholder SVGs with your Hum3D exports:

1. Open your SVG in Illustrator/Figma
2. Name the paintable body layer group: **`wrap-body`**
3. Keep wheels, windows, trim in separate groups: `wheels`, `windows`, `trim`
4. Save as:
   - `public/wraps/svg/bmw-m4.svg`
   - `public/wraps/svg/mercedes-g-wagon.svg`

The configurator dynamically changes `#wrap-body` fill colour and applies finish effects (gloss shine, matte flat, chrome gradient, carbon pattern).
